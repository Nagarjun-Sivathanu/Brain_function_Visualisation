# Region Summary: Left Mammillary Body

**Region name:** left mammillary body
**Hierarchy level:** 5
**Parent:** hypothalamus
**Major components:** —

---

## 1. Overview

The left mammillary body is the left hypothalamic memory relay of the Papez circuit. It is responsible for relay of hippocampal output (via the fornix) onward to the anterior thalamus, serving recollective memory.

## 2. Detailed Functional Description

- **Relay memory signals.** Receive hippocampal output through the fornix and project via the mammillothalamic tract to the anterior thalamus (Papez circuit).
- **Support recollection.** Provide a node for episodic memory and spatial/emotional context.

## 3. Behavioural Description

Bilateral damage (classically thiamine deficiency / Wernicke–Korsakoff) causes profound anterograde amnesia and confabulation.

## 4. Functional Mimicry Notes (for agent modelling)

Model as a memory-circuit relay nucleus forwarding hippocampal signals to the thalamus.
