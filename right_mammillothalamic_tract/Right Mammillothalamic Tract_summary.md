# Region Summary: Right Mammillothalamic Tract

**Region name:** right mammillothalamic tract
**Hierarchy level:** 4
**Parent:** diencephalon
**Major components:** —

---

## 1. Overview

The right mammillothalamic tract is the right white-matter link of the Papez memory circuit. It is responsible for connection from the right mammillary body (hypothalamus) to the right anterior thalamic nucleus, a key leg of the Papez circuit.

## 2. Detailed Functional Description

- **Close the Papez loop.** Carry signals from the right mammillary body to the right anterior thalamic nucleus, linking hypothalamus → thalamus → cingulate → hippocampus.
- **Support episodic memory.** Provide the anatomical substrate for recollective memory and emotional context.

## 3. Behavioural Description

Damage (classically in thiamine deficiency / Korsakoff syndrome) produces severe anterograde amnesia and confabulation.

## 4. Functional Mimicry Notes (for agent modelling)

Model as a memory-circuit relay cable: it forwards limbic signals through the thalamus rather than computing.
