# Region Summary: Left Metathalamus

**Region name:** left metathalamus
**Hierarchy level:** 5
**Parent:** thalamus
**Major components:** left lateral geniculate body, left medial geniculate body

---

## 1. Overview

The left metathalamus is the left sensory geniculate relay for vision and hearing. It is responsible for the left lateral geniculate (visual) and medial geniculate (auditory) relays to cortex.

## 2. Detailed Functional Description

- **Relay vision.** The lateral geniculate nucleus relays retinal input (a visual hemifield) to the primary visual cortex, organising it for conscious sight.
- **Relay hearing.** The medial geniculate nucleus relays inferior-colliculus auditory output to the primary auditory cortex.

## 3. Behavioural Description

Lesions cause a contralateral visual-field defect (LGN) or central hearing deficits (MGN).

## 4. Functional Mimicry Notes (for agent modelling)

Model as two dedicated sensory relays — a visual channel and an auditory channel — into cortex.
