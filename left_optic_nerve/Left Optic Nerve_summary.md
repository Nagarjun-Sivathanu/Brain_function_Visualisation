# Region Summary: Left Optic Nerve

**Region name:** left optic nerve
**Hierarchy level:** 4
**Parent:** diencephalon
**Latin / meaning:** "cranial nerve II"
**Major components:** —

---

## 1. Overview

The left optic nerve is the left visual input cable carrying retinal output from the left eye toward the brain. It is responsible for transmission of visual signals from the left retina to the optic chiasm, preserving the retinotopic map.

## 2. Detailed Functional Description

- **Carry retinal output.** Convey the axons of left-retinal ganglion cells (a CNS white-matter tract, myelinated by oligodendrocytes) toward the optic chiasm.
- **Preserve the visual map.** Maintain retinotopic order so downstream targets can reconstruct the visual field.
- **Serve the light reflex.** Provide the afferent limb of the pupillary light reflex.

## 3. Behavioural Description

Damage to the left optic nerve causes vision loss in the left eye and an afferent pupillary defect; it does not, by itself, cause a field cut respecting the vertical meridian (that begins at the chiasm).

## 4. Functional Mimicry Notes (for agent modelling)

Model as a faithful input cable: it transmits and preserves the visual signal but does not interpret it.
