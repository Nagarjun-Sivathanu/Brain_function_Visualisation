# Region Summary: Anterior Commissure

**Region name:** anterior commissure
**Hierarchy level:** 4
**Parent:** telencephalon
**Major components:** —

---

## 1. Overview

The anterior commissure is a smaller commissure linking the temporal lobes and olfactory structures across the midline. It is responsible for interhemispheric connection of the temporal lobes, amygdalae, and olfactory regions.

## 2. Detailed Functional Description

- **Connect temporal/olfactory regions.** Carry fibres between the two temporal lobes, amygdalae, and olfactory areas, complementing the corpus callosum.
- **Support bilateral emotion/olfaction.** Help integrate emotional and olfactory information across hemispheres.

## 3. Behavioural Description

A compact white-matter bundle; it provides an accessory route of interhemispheric transfer that can partly compensate for callosal damage.

## 4. Functional Mimicry Notes (for agent modelling)

Model as a secondary interhemispheric cable for temporal/limbic/olfactory traffic.
