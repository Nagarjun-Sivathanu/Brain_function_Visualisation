# Region Summary: Optic Chiasm

**Region name:** optic chiasm
**Hierarchy level:** 5
**Parent:** hypothalamus
**Latin / meaning:** "crossing (X)"
**Major components:** —

---

## 1. Overview

The optic chiasm is the X-shaped crossing where the optic nerves partially decussate. It is responsible for the partial decussation of the optic nerves: nasal retinal fibres cross, temporal fibres stay, sorting vision into hemifields.

## 2. Detailed Functional Description

- **Sort vision into hemifields.** Cross the nasal-retinal fibres of each eye while leaving the temporal fibres uncrossed, so each optic tract carries the opposite visual hemifield from both eyes.
- **Set up binocular field maps.** Establish the wiring that lets each hemisphere see the contralateral half of visual space.

## 3. Behavioural Description

A midline chiasm lesion (classically a pituitary tumour pressing from below) causes bitemporal hemianopia by interrupting the crossing nasal fibres.

## 4. Functional Mimicry Notes (for agent modelling)

Model as a fixed routing junction that re-sorts visual cables into hemifields; it routes, it does not process.
