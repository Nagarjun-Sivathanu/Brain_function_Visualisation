# Region Summary: Right Occipital Lobe

**Region name:** right occipital lobe
**Hierarchy level:** 5
**Parent:** right cerebral hemisphere
**Major components:** primary visual cortex (V1, calcarine), visual association areas (V2–V5), cuneus, lingual gyrus

---

## 1. Overview

The right occipital lobe is the right visual lobe — the brain's primary sight processor. It is responsible for reception and analysis of the left visual hemifield: edges, motion, colour, depth, and form.

## 2. Detailed Functional Description

- **Receive vision.** Primary visual cortex (V1) in the calcarine sulcus receives the left visual hemifield from the lateral geniculate nucleus.
- **Extract features.** Association areas analyse orientation, motion (V5/MT), colour (V4), and depth.
- **Feed the what/where streams.** Pass processed vision forward to the temporal ('what') and parietal ('where') pathways.

## 3. Behavioural Description

Damage causes a contralateral (left) homonymous visual-field loss; specialised lesions cause motion blindness, achromatopsia, or visual agnosia.

## 4. Functional Mimicry Notes (for agent modelling)

Model as the visual front-end: it turns retinal/thalamic input into edges, motion, and colour and hands them to higher streams.
