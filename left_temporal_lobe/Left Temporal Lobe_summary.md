# Region Summary: Left Temporal Lobe

**Region name:** left temporal lobe
**Hierarchy level:** 5
**Parent:** left cerebral hemisphere
**Major components:** superior/middle/inferior temporal gyri, transverse temporal gyrus (primary auditory cortex), fusiform gyrus, hippocampus (medial), amygdala (medial), temporal pole

---

## 1. Overview

The left temporal lobe is the left lobe for hearing, language, memory, and object/face recognition. It is responsible for auditory processing, language comprehension, declarative memory (hippocampus), emotional salience (amygdala), and high-level visual recognition (fusiform).

## 2. Detailed Functional Description

- **Process hearing.** Primary auditory cortex (Heschl's gyrus) and association areas analyse sound, speech, and music.
- **Handle language/meaning.** It contains Wernicke's area for language comprehension.
- **Form declarative memory.** The hippocampus and medial temporal lobe encode and consolidate facts and events.
- **Recognise objects and faces.** The fusiform/inferior-temporal 'what' pathway identifies objects, words, and faces; the amygdala tags emotional significance.

## 3. Behavioural Description

Damage causes auditory and recognition deficits, memory impairment (medial temporal), and — on the left — Wernicke's (receptive) aphasia; bilateral medial damage gives severe amnesia (cf. patient H.M.).

## 4. Functional Mimicry Notes (for agent modelling)

Model as the 'what + memory + meaning' lobe: it identifies sounds/objects, attaches meaning and emotion, and lays down memories.
