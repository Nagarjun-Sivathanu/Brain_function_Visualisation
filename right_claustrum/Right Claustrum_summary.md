# Region Summary: Right Claustrum

**Region name:** right claustrum
**Hierarchy level:** 5
**Parent:** right cerebral hemisphere
**Major components:** —

---

## 1. Overview

The right claustrum is a thin sheet of grey matter implicated in integrating cortical activity and consciousness. It is responsible for widespread reciprocal connections with the cortex, proposed to coordinate and synchronise cortical processing into unified conscious experience.

## 2. Detailed Functional Description

- **Integrate cortical activity.** Connect reciprocally with almost all cortical areas, potentially binding distributed processing into coherent perception.
- **Coordinate attention/salience.** Proposed to help orchestrate attention and the timing of cortical networks.

## 3. Behavioural Description

Its function is still debated; stimulation/lesion evidence links it to the level of consciousness and the integration of multimodal information.

## 4. Functional Mimicry Notes (for agent modelling)

Model as a cortical conductor/synchroniser node with broad reciprocal links, integrating rather than computing a specific modality.
